# 가치커피 소개 브로셔 (A4 십자 접지, 8면) — 내용 제안·시안 3개

소반 아래 비치, 손님이 가져가는 용도. A4 한 장을 가로 1번 + 세로 1번 접어 **평소에는 1/4(A6, 105×148mm)**.
펼치는 순서: 앞표지 → 한 번 펼치면 2·3면(A5 가로) → 다 펼치면 4~7면(A4 한 장).

## 넣지 않는 것
- **카페쇼 한정 혜택**(무료배송·드립백 증정·11/19 발송·가입 쿠폰): 행사 뒤 남은 브로셔를 계속 쓰려면 빼고, 원두 주문 QR 카드에만 둔다.
- 납품가: 소비자용 인쇄물에 넣지 않음(B2B 매뉴얼).
