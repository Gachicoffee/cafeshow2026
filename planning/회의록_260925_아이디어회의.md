## 2. 논의 흐름

### ① "맛 vs 가치" 두 유형 (기존안 변형)
- 오전의 "맛/기분"을 "맛을 중시하는 사람 / 가치를 중시하는 사람"으로 바꾼 안 [00:04]
- 반론: 가치를 중시하면 맛은 중요하지 않다는 뜻이냐 → 제공하는 커피는 똑같고 **설명 방식만 다르게** (맛 위주 vs 가치·스토리 위주)
- 블렌드별 가치 키워드 (가제): 코스모스 = 기분전환, 구수 = 편안함, 보통 = 위로(어렵다), 허브 계열 신규 블렌드 = 개성·나다움
- 보완 의견: 가치를 감성으로만 풀면 추상적 → **감성적인 질문을 던지고 답은 실제 커피 맛으로 확인**하게 해야 완성됨 [02:18~02:28]
- 반대 의견: 블렌드를 상황·감정에 매칭하는 것 자체가 주입식이고 뻔함 → 의미는 살리되 방법을 바꾸자

### ② 새 제안 — "경쟁·맞히기" 액티비티
출발점: 사람은 **맞혔을 때, 이겼을 때** 단순하지만 확실한 즐거움을 느낀다 ("이거 이즈니 버터죠?" 맞혔을 때의 쾌감) [05:18~06:43]

| 아이디어 | 방식 | 논의 |
|---|---|---|
| **가치커피 사장님을 이겨라 (추출 배틀)** | 사장님과 손님이 나란히 같은 커피를 내리고, 지나가는 사람이 블라인드로 더 맛있는 쪽을 고름. 손님이 이기면 선물 | 핸드드립은 최소 3분 걸리고 부담스러움 → **드립백으로 하면 물만 부으면 됨**. 직접 해보고 + 이기는 성취감 → 기억에 남음. 져도 잃을 게 없음 [07:06~08:49] |
| **커피 지식 배틀** | 박스에서 질문 카드 뽑기 → 손님이 먼저 답하고 사장님이 나중에 답함. 맞히면 칭찬 + 선물 | OX처럼 쉬운 것부터 어려운 것까지 섞을 수 있음 [09:03~09:56] |

- 제안자 의견: 종이에 쓰고 추천받고 가는 체험은 인상에 안 남음. **직접 하고 머리를 쓰는 체험일수록 기억에 남음** [10:17~11:13]
- 다른 참석자: 직관적이라 오히려 나을 수 있다고 동의

### ③ 브랜드 분위기와 맞아야 하나
- 한 참석자: 가치커피의 차분한 분위기·인쇄물 톤에는 **감성적인 방향이 더 어울린다고 생각했다** [11:26~11:48]
- 제안자: 꼭 그럴 필요 없다. 감성형 부스는 카페쇼에 많아서 인상적이지 않았음
- 예시 — **빔브라더스 카페쇼 부스**: 부스 8~10칸 규모로 매장을 통째로 옮겨옴. 주문을 받고 코스별로 시음시키며 추출하는 모습을 보여주고 대화함 → 다들 기억함. 부스는 공장처럼 거칠었지만 실제 매장·직원은 차분하고 정돈됨 → **부스 콘셉트가 브랜드 톤과 꼭 같을 필요는 없다**는 예시 [12:01~15:07]
  - (규모·자본 덕이 크다는 반론도 있었음)
