# 미니 브로셔 하빈 시안 검토 (10/30)

대상: `시음존_브랜드 소개서(편지 형식)_폰트깸.ai` (A4 2장 = 바깥면 4칸 + 안쪽 펼침 1장). 방법: design-critique 틀(첫인상·쓰임·위계·통일·읽기 쉬움) + 사실 대조(지식베이스·행사정보·원고 v3).

## 첫인상
검정 굵은 고딕 + 가는 선 격자 + 사진이 잡지처럼 정돈돼 있고, 표지 항공우편 테두리가 "편지"를 한눈에 알려 준다. 쌓인 인쇄물 속에서도 눈에 띈다.
문제는 **같은 역할의 요소가 여러 모양으로 반복**되는 것: 번호 01이 세 벌, 영어 꼬리표가 면마다, 사이트·인스타 주소가 네 번, 굵은 큰 글씨가 한 면에 두 개씩. 그래서 어지러워 보인다.

## 2. 통일 규칙 (어지러움의 원인)
| 요소 | 지금 | 규칙 제안 |
|---|---|---|
| 번호 | 바깥 "01 OUR SPACE", 안쪽 01·02·03, 블랜드 01~04 — 01이 세 번 | 큰 번호는 **안쪽 이야기 01·02·03만**. 바깥 01 빼기. 블랜드는 큰 숫자 대신 작은 색 점이나 작은 숫자 |
| 면 번호 | 03·08만 있음 | 전부 빼기(8면 브로셔라 필요 없음) |
| 영어 꼬리표 | HI, COFFEE LOVER · OUR SPACE · OPEN · Location · STRENGTH… · Letter from Yeosu · SINCE | 영어는 **브랜드·블랜드 이름과 THE NAMDO HANSANG만**. 나머지는 한글로 (예: Location → 찾아오시는 길, 기준 4개 → 향의 강도·선명함·단맛·깨끗함) |
| 말투 | 해요체 + 안쪽 02 본문만 합니다체("존재합니다·전하고자 합니다") | 전부 해요체. 맨 아래 "감사합니다." 한 줄만 예외(회사 인사말) |
| 우리/저희 | 우리의 커피·우리가 하는 일·우리의 철학 ↔ 저희 하나·저희 커피 | 손님에게 쓰는 글이라 **저희**로 통일(제목 "우리가 좋아하는 커피가"는 ABOUT 문장이라 둬도 됨) |
| 굵은 큰 글씨 | 2면에 안녕하세요 + 남도 유일 참가, 표지에 편지가 왔어요 + 2017 | **면마다 하나만**. 2면은 "안녕하세요", 표지는 "편지가 왔어요". "전남 유일 참가"·"2017"은 한 단계 작게 |
| 주소 줄 | gachicoffee.com/@gachi_coffee가 안쪽 3번 + 뒷면 | **뒷면 한 번만** |
| 블랜드 설명 끝맺음 | 첫 잔 / 선명했던(명사 없음) / 라떼 / 마무리되던 잔 | 모두 "~잔"으로: 복숭아 향이 나던 첫 잔 · 허브 향이 선명하던 잔 · 죠리퐁 우유 같던 라떼 · 새콤하다 초콜릿으로 끝나던 잔 |

## 3. 덜어낼 말 (의미 없는 말)
- 2면 "HI, COFFEE LOVER" — 바로 아래 "안녕하세요"와 겹침 → 빼기
- 2면 "수려한 물의 도시 여수를 잘 느낄 수 있도록 … 시그니처 커피 4잔" — 꾸밈말이 많고 뜻이 약함 → "여수 바다 대신 커피 네 잔을 싸 들고 올라왔어요."
- 3면 "OPEN" — 아래 "펼치면 편지가 이어져요 →"만으로 충분
- 표지 "Letter from Yeosu" — 한글 제목과 같은 말 → 빼기
- 표지 "SINCE 2017" 큰 칸 — 3면에 2017 이야기 있음 → 작게 줄이거나 빼고 그 자리에 여수 사진 크게
- 안쪽 01 "먼 산지의 좋은 커피를 당신에게 전하는 일, / 우리가 하는 일이 그거예요." — 쉼표로 끊긴 제목 → "먼 산지의 좋은 커피를 당신에게 전하는 일." + 작은 글씨 "저희가 하는 일이에요."
- 안쪽 02 본문(ABOUT 원문 두 단락) — 손님 말 인용과 주제가 다름 → 해요체 두 줄로: "같은 농장 커피도 수확 시기와 가공에 따라 맛이 달라요. 그중 향이 선명한 커피를, 지속가능한 커피를 만드는 생산자에게서 골라요."
- 안쪽 02 위 "이렇게 말씀해 **주세요**" — 부탁처럼 읽힘 → "이렇게 말해 주셨어요."
- 안쪽 03 본문 세 단락(가치 뜻 · 카페쇼 소반 · 1년 수확) — 한 칸에 세 이야기 → 앞 두 단락만. "노력할게요" 빼기. 수확 이야기는 02로 옮기거나 빼기
- 8면 "여기서 주문할 수 있어요!" — 느낌표 빼고 "찍으면 바로 주문 페이지예요"
- Location 영어 주소 두 줄 — 손님 대부분 한국인 → 빼면 칸이 숨 쉼

## 4. 잘된 점 (그대로 두기)
- 표지 항공우편 테두리 + "여수에서 편지가 왔어요": 쌓인 인쇄물 속에서 가장 먼저 보임
- 2면 직원 사진: "사람이 있는 가게"라는 기억을 남김
- 안쪽 큰 인용 "향이 선명하고 강해요" — 손님 말을 가장 크게 둔 판단이 좋음
- 파란 손그림 화살표가 01→02→03→찾아오는 길로 읽는 순서를 잡아 줌
- 블랜드 네 줄을 한 칸에 모은 것(블랜드는 1면만 원칙에 맞음)

## 5. 우선순위
1. **사실·인쇄 오류**(1~11) — 산방산 사진·SYDNEY·남도 유일·맞춤법·접지 방향
2. **번호·영어·주소 줄 정리** — 이것만 해도 어지러움 절반이 줄어듦
3. **안쪽 02·03 본문 줄이기와 해요체 통일**
