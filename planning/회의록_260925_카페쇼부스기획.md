## 2. A안 — 취향 유형 테스트 (MBTI T/F 변형)

**구성 (발표안)**
1. 대기 줄에서 종이 배포 → 간단 체크: "나는 커피를 **맛으로** 기억한다 / **기분으로** 기억한다"
   - MBTI를 직접 쓰지 않고 이 문구로 바꿈
2. 맛형 → 향미·블렌드 맛 매칭 게임 / 기분형 → 지금 기분·상황에 맞는 블렌드 추천
3. 4종 블렌드 시음 → 가장 좋았던 블렌드 투표 (생략 가능)
4. 작성지 + 아카이브 노트 제공, 굿즈는 팔로우 조건

**장점**: 익숙한 형식, "나는 어느 쪽?" 호기심 자극, 맛 중심·감성 중심 고객 모두 공략, 4종 블렌드로 연결

**우려**
- MBTI 콘텐츠 피로감, 뻔한 성격 테스트처럼 보임, 커피 취향이 MBTI와 연결된다는 오해
- 1인당 5~7분 → 회전율 저하, **운영 인력 4명**으로 감당 가능한지 테스트 필요
- (회의 중 지적) 맛/기분으로 나눠도 결국 4종 시음·투표로 합쳐져서 **분기의 의미가 약함**, 구체적인 질문 예시가 있어야 판단 가능

**보완안**: 대기 중 체크 진행, 투표 간소화, 4명 역할 분담 정리

## 4. 가격·비용 논의

- 드립백 1개 판매가 2,500원. 배송비 500원을 붙여 3,000원 안이 나왔으나 "원가에 가깝게 파는 게 맞나"는 의견
- 박람회에서는 보통 할인가로 판매하는데, 2,000~3,000원 차이는 체감이 크지 않고 **5,000원까지는 낼 만하다**는 의견. 1만원이 넘으면 부담
- 돈을 벌러 가는 행사가 아니라 인지도가 목적 → 일부 인원에게 무료 발송은 **투자로 보자**
