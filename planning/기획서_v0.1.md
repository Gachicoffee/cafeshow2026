# 남도 커피 백반기행 기획서 v0.1 (10/2~10/3 대화 정리)

> 70개 부스가 종이컵을 건네줄 때, 가치커피는 상을 차려 드린다.

맛의 고장 전라도에서 올라온 커피 한상. 반찬은 기본, 덤은 인심. 주인공은 구수 라떼. 관람객이 느낄 감정은 "대접받았다", 톤은 정갈한 남도 한상.

## 아이디어 거르는 기준 5가지
| 기준 | 질문 |
|---|---|
| ① 즉시 보상 | 그 자리에서 손에 남는 게 있나? 체험은 무료(구매는 원하는 사람만) |
| ② 굳이 여기 | 다른 로스터리도 할 수 있는 것 아닌가? |
| ③ 억지 아님 | 브랜드가 감성을 주장하지 않고 관람객이 스스로 느끼나? |
| ④ 브랜드 연결 | 게임만 하고 가 버리지 않나? |
| ⑤ 현실성 | 3×2m, 2~3명, 2kW, 예산 안에서 돌아가나? |

대표가 원하는 감정: 감동, 게임 같은(내가 이기는), 재미, 놀라움, 기분 좋게 해 주는.

## 컨셉
- 전라도라는 **장소**가 아니라 **정서**(맛의 고장·반찬·인심·덤)를 빌림. '구수하다'는 밥상 언어라 구수 블렌드와 바로 연결.
- 톤: 나무 소반, 흰 사기잔, 조각보 상보, 손글씨 차림표. 재미는 문구에서, 보이는 건 정갈하게. 기사식당 느낌·자기 비하 유머는 쓰지 않음.
- 이름: "커피 백반기행" 또는 "남도 커피 기행". TV '백반기행' 로고·서체는 흉내 내지 않음.

## 한상 흐름 (전부 무료)
1. **3초**: 덮개 씌운 소반이 줄지어 있고, 움직이는 숫자(오늘 차려 드린 상)가 보임
2. **여는 순간**: 관람객이 상보를 직접 걷음 → 미니컵 한상 `채택`
3. **반찬**: 코스모스(꽃향) · 이번 주 싱글오리진 · 보통 등, 1oz 소량
4. **마지막**: 구수 라떼. "식사 끝엔 숭늉이죠" `후보`
5. **리필**: 마음에 든 반찬 한 번 더 → 대화 시작점
6. **배웅**: 차림표(쿠폰 QR)를 들고 떠남

## 판매와 덤
| 구분 | 방식 | 이유 |
|---|---|---|
| 드립백 | 현장 판매는 드립백만. "밑반찬 세트", 보자기 포장 후보 | 입문자는 그라인더가 없고 선물로 좋음 |
| 원두 | 현장 결제 → 다음 주 여수에서 갓 볶아 발송 | "갓 볶아 보내 드려요"가 좋은 키워드 |
| 덤 | 사는 사람에게 얹어 줌. 다 비운 상엔 "싹 비움" 도장(온라인 쿠폰 할인율↑) 후보 | 모두에게 드립백을 주면 4일 약 1,000개 |
| 납품 | 사장님께 샘플 + 머신 무료 점검 쿠폰 | 엔지니어 이력 활용, 장비 전시는 안 함 |

처리량: 한 상 1~1.5분, 2명 기준 시간당 40~50상 → **하루 300~350상, 4일 1,200~1,400상**.

## 세부 후보 (대표 선택 대기)
| 상태 | 아이디어 | 내용 |
|---|---|---|
| 채택 | 상보 걷기 | 조각보 덮개를 관람객이 직접 걷음. 릴스 장면 |
| 후보 | 마지막은 숭늉 | 구수 라떼를 마지막 잔으로 |
| 후보 | 밥공기 뚜껑 | 구수 라떼는 뚜껑 있는 작은 공기에 |
| 후보 | 메뉴판 "백반 0원" | 가격 전부 0원, 무료임을 설명 없이 전함 |
| 후보 | 원산지 표시판 | "원두: 에티오피아… / 볶은 곳: 전라남도 여수" |
| 후보 | 수저 봉투 차림표 | 앞면 오늘의 상, 뒷면 쿠폰 QR |
| 후보 | 오늘의 상 | 수·목·금·토 매일 다른 싱글오리진, "남은 상 87" |
| 후보 | 겸상 | 2인 한 상. 가치(같이)커피, 처리량 증가 |
| 후보 | ○○ 씨네 커피 | 차림표에 생산자 이름 |
| 후보 | 주인장 장 보러 갔습니다 | 대표 부재를 프로그램화, 다녀온 부스를 보드에 추가 |
| 후보 | 맛집 벽 | 옆벽 한지 카드 한 줄 평, 아날로그 스코어보드 |
| 후보 | 상 물림 인사 | "같이해 주셔서 감사합니다", 광목·쪽빛 앞치마 |
| 후보 | 식당 역할 나누기 | 주인장·찬모(추출)·상차림(서빙·계산), 덮은 상 2~3개 대기 |
| 후보 | 종지 잔 | 간장 종지 크기 흰 사기잔, 다회용 |
| 후보 | 호출벨 | 리필은 벨로, 누른 횟수 = 실시간 인기 반찬 |
| 후보 | 커피콩 초콜릿 | 계산대 박하사탕 자리 |
| 후보 | 밑반찬 세트·보자기 | 드립백 3종·5종 세트 |
| 후보 | 반찬 배달 | "다음 주 여수에서 반찬 배달 갑니다", 정기배송 연결 |
| 후보 | 단골 장부 | 사장님 명함 기록 → 샘플·점검 쿠폰 발송 |
| 후보 | 늦가을 한상·원두 김장 | 11월 계절 문구 |
| 보류 | 물티슈·식권·재료 소진 마감 | 여력이 되면 |
| 보류 | 줄 세우기 방식 | 회차제·번호표 등은 프로그램 확정 뒤 |

## 내려놓은 아이디어 (요약)
- 폐기: 맛/기분 유형 테스트, 벌새 우체국, 커피 처방전, 내 블렌드 만들기(유료), 여수 가챠, 여수 여행 경품, 절대미각 랭킹 등 게임류, 로스팅 기록 공개, 신선도 비교, 1:1 커핑, 지역 페어링, 여수 생중계 로스팅, 구수 맛 퀴즈, 엔지니어 정비소(점검 쿠폰만 살림), 촌놈 상경기·오일장, 김치 숙성도, 원두 현장 판매, 다 비우면 드립백 무료.
- 보류: 바리스타를 이겨라·가격 맞히기, 여수까지 가자(승선권), 다음 주 커피 투표·취향 좌표 카드·커피앨리 지도.
