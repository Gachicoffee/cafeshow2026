# 서울카페쇼 사무국 공지 요약 (메일 63건, 10/28 기준)

출처: 대표 Gmail에서 모은 공지 원문(참가사 공지 vol.1~17 포함). 로그인 정보·계좌·개인 연락처는 넣지 않았다.

## 확정된 사실
- 부스 **CA107**(커피앨리, C홀). 삼각지붕 간판 시안에 GachiCoffee 로고(벌새) 정상 표기, 사무국 지적 사항 없음(수정 마감 10/20 지남).
- 참가비 2,200,000원(VAT 포함) + 부대시설 1차 440,000원(VAT 포함) **모두 납부 완료**(10/21 인보이스, 미납 0원).
- **신청된 부대시설: 전기 220V 1kW 추가 1건 + 급배수 1개소.** 조립부스 기본 1kW 포함 → **현재 총 2kW**. 급배수 서약서 접수 완료(10/6).
- 주차권은 앨리 참가사 미포함. 모바일 초청장은 참가관리시스템에서 행사 종료일까지 발송(추가 10매 125,000원).
- 가치커피는 **엔조이카페(공식 파트너 카페)**로도 선정 → 엔조이카페용 모바일 초청장도 따로 발송 가능(~11/14, 문자 발송).
