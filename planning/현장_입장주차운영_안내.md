# 현장 입장·주차·운영 안내 (11/7 정리)

출처: 사무국 공지 vol.20(11/5) 첨부 「참가사 현장 공지」 PDF, vol.17(짐 보관), 커피앨리 공지(11/4 리유저블 컵). 현장 사무국 **02-6002-8000**(11/9~14, 전화가 안 되면 카카오톡 챗봇).

| 시간 | 할 일 | 어디 |

| 12:00~20:00 | 앨리부스 전시품 반입·세팅 (12시 전에는 부스 공사 중이라 입장 불가) | C홀 CA107 |

추천 순서: 출입증(C1) → 웰컴키트(2F) → 반입 → 부대시설 확인 → 세팅.

### 차와 주차
- **무료 3시간**: 1톤 이상 트럭, 화물 승합(번호판 앞자리 7·8·9)만. 서문 게이트로 들어와 화물 출입구 근처 QR로 직접 등록.
- **승용차·SUV·10인 이하 승합**: 무료 없음, 화물 로딩독에 들어갈 수 없음 → 일반 주차장에 대고 짐을 손으로 옮김.
- 일반 요금: 15분 1,500원, 하루 60,000원(입차 20분 안에 나가면 무료).
- **참가사 할인권: 하루 30,000원(50%)**. 각 홀 입구 X배너 QR 또는 공지 링크로 구매, 가입 없음, 나갈 때 할인권 적용·결제.
- 커피앨리는 무료 모바일 주차권 없음.

### 차 없이 드나들기
- 출입증을 차고 C1 입구 등 전시장 출입구로 들어감. 참가사 입장 시간 안이면 언제든 출입 가능.

## 11/11(수)~14(토) 운영일
| | 수~금 | 토 |
|---|---|---|
| 참가사 입장 | 08:00~18:30 | 08:00~20:00 |
| 관람객 | 10:00~18:00 (입장 17:30까지) | 10:00~16:00 (입장 15:30까지) |
| 급수 | 전시 30분 전 ~ 18:30 | ~16:30 |
| 반출 | | 16:30~20:00 (부스 철거는 11/15 장치사가 함) |

- **주차**: 코엑스 일반 주차장 + 할인권 하루 30,000원. 따로 정해진 참가사 주차 구역은 공지에 없음.
- **동선**: 주차장 → C홀 입구(3층) 출입증 제시 → 커피앨리 CA107. 매일 퇴장 때 **수도 밸브 잠그기**.
- **짐 보관**: 참가사 전용 무료 창고는 없음. 짐캐리 센터(1층 B홀 앞 로비, 3층 D홀 앞 로비)의 **장기 보관은 사전 접수한 업체만**, 유료·카드만, 운영 시간 안에만 넣고 뺌. 국내 택배 14:00까지 접수하면 당일 집하(14일은 14:00 전 방문 권장), 박스·테이프 현장 구매 가능.

### 쓰레기·설거지
- **반입하며 생긴 폐기물은 100% 다시 가지고 나감**(공지 예시: 비닐·플라스틱·목재·박스·코팅 종이·에어캡). 안 지키면 비용 청구. 행사 중 나오는 작은 일반 쓰레기를 홀 쓰레기통에 버려도 되는지는 공지에 없음 → 사무국 확인(작년 커피엑스포는 홀 쓰레기통 허용).
- 커피박: 주최자 사무실에서 봉투를 받아 담고 **C-D홀 연결통로** 수거함에.
- 음식물(남은 커피·우유 포함으로 보는 게 안전): 각 층 **화물 로딩독** 수거통(C-D 연결통로 게이트로 이동).
- 다 쓴 컵: 내용물 비우고 **커피앨리 워터스테이션 옆 스폰서 부스** 컵 수거 공간에.
- 리유저블 컵 200개를 현장 요원이 부스로 갖다 줌 → 다 쓰면 커피앨리 스폰서 부스 반납 장소에.
- **설거지 장소는 공지에 없음.** 바닥 트렌치·배수관에 액체를 붓는 것은 금지(누수). 서버·피처는 워터스테이션에서 씻을 수 있는지 11/10 사무국에 확인.

### 사고가 나면
- **누수**: 바로 밸브 잠금 → 사무국 02-6002-8000. 바닥 방수가 안 돼 감전·침수 위험. 우리 설비 부주의로 생긴 누수 손해는 참가사가 배상.
- **전기**(C·D홀): 정성전기 · **급배수**(C홀): KD엔지니어링 · **부스·조명**(3층): 메쎄바우 → 직통 번호는 현장 공지 PDF 6쪽.
- **도난·파손**: 주최 측 책임 없음. 반출·철거 때 1명 이상 부스에 남기, 노트북·카메라 주의.
- 그 밖의 일은 모두 2층 주최자 사무실 또는 02-6002-8000.
